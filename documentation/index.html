KApplication

            
KApplication is the core class of KiteGUI. It manages the Windows message loop and handles events.

            
Usage:

            

            

                app.run() starts the application's event loop and processes Windows messages.

                You only need one KApplication per application.
            

        


        


        

            
KWindow

            
KWindow represents a native Windows window in KiteGUI. It accepts three parameters: KApplication& app, std::string title, std::pair<int, int> size.

            
Usage:

            

            
You can have multiple windows in your application.

KButton

            
KButton is a clickable button. It accepts four parameters: KWidget& parentWidget, std::string text, std::pair<int, int> location, std::pair<int, int> size.

            
Usage:

            

            

                onClick() sets a function that is called when the button is clicked

                Remember, always pass objects that you want to use in the lambda function.
