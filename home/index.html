What is KiteGUI?

            
KiteGUI is a simple, object-oriented C++ GUI framework. It acts as a "wrapper" around the WinAPI, simplifying almost everything it has to offer. The core purpose of this library is to make the application creation process as simple as possible. For example, a window can be created by declaring just a single variable. See the Examples page to see just how easy it is.

        


        


        

            
Why use KiteGUI?

            
    
                
  • 
                    
    Simple
    
                    
    No massive dependencies or complex build systems. Just link the library and start compiling right away.
    
                
    • 
                
  • 
                    
    Lightweight
    
                    
    KiteGUI wraps the WinAPI library into classes, functions, and variables; so basically, you get the same speed as a native WinAPI application but with 10x less work.
    
                
    • 
                
  • 
                    
    Limited Only by Your Creativity
    
                    
    You don't need to know the WinAPI or worry about its complexity and errors. KiteGUI handles the hard part, so you can focus on building whatever you imagine.
